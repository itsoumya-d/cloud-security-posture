# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-11-21
### Added
- Detection-as-Code engine with MITRE ATT&CK mapping (T1078.004, T1548).
- Rule lifecycle state transitions and suppression filters.
- Pre-rollout rule test harness.
- Alert triage pipeline with entity velocity tracking and automated STS containment actions.
- Failure injection test suites for malformed telemetry resilience.

## [1.0.0] - 2026-11-14
### Added
- Initial cloud security posture engine release.
- Account sync and CIS-style posture evaluation.
- HISO / NZISM health compliance benchmarks.
